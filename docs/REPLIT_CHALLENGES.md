# Challenges we faced using Replit

During MoneyVerse's artwork creation and deployment attempts, we encountered the following challenges:

- **Repeated artwork attempts:** Creating the game's images and illustrations required many attempts. Several outputs did not meet our expectations, so we revised prompts and retried generation before getting usable artwork.

- **Limited credits:** The repeated generations and retries consumed almost all of our available Replit credits, leaving little room for further experimentation.

- **Deployment difficulties:** After working on the artwork, we attempted to host MoneyVerse on Replit. Getting the deployed experience to behave as expected became another challenge.

- **Missing animations:** During our Replit deployment attempts, some animations did not play as expected, including the floating whale and floating character effects. This affected the movement and atmosphere of the game world.

- **Unconfirmed environment differences:** We suspected differences in the Node.js runtime or installed dependency versions might be related to the animation problems. However, we did not confirm the root cause, so we cannot attribute the failures to a specific version change or to Replit itself.

These challenges highlighted the importance of budgeting for generation retries and checking the deployed game's visual behaviour alongside its build results.
