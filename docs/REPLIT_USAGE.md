# How we used Replit

MoneyVerse is an interactive financial-literacy game built around planning, saving, investing, and financial safety. We used Replit for prompt-based image and artwork creation as part of the project's visual development.

## Replit's role

Our use of Replit centred on **AI-assisted visual asset creation**: expressing art ideas through natural-language prompts to create imagery for the game's illustrated world. This supported the visual side of an experience where students explore locations and learn through decisions.

The project's art direction combines warm colours, inked outlines, illustrated environments, and playful characters. These visual guidelines are documented in [DESIGN.md](../DESIGN.md), while the repository's art-loading code and visual assets live in `src/art/` and `public/art/`.

## Illustrative prompt

The following example communicates the project's visual direction; it is not a saved transcript of an actual Replit prompt:

> Create a welcoming illustrated shop for a student financial-literacy game. Use warm terracotta, marigold, and teal colours, bold inked outlines, and a playful cartoon style. Keep the silhouette clear and leave space around the entrance for game interactions.

## Place in the project

Replit contributed to the creative artwork workflow. The application uses React, TypeScript, and Vite, with Supabase supporting the teacher portal and student-progress features. See the [project README](../README.md) for gameplay, setup, and backend details.
